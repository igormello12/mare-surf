# 🌊 Maré — No seu ritmo

Curadoria de destinos de surf no Brasil para surfistas brasileiros escolherem a próxima trip com mais contexto e confiança.

## Sobre

A **Maré** organiza destinos com linguagem simples, contexto real de viagem e clima de descoberta. Menos ruído, mais sensação de "esse lugar é a minha cara".

## Destinos MVP

- 🏄 **Florianópolis** — Versátil, cidade + praia
- 🌿 **Ubatuba** — Mata atlântica, constância
- 🌴 **Itacaré** — Tropical, Bahia
- 🐧 **Garopaba** — Sul, ritmo calmo
- 🏆 **Saquarema** — Performance, tradição

## Stack

Site estático em HTML/CSS/JS puro. Zero dependências de servidor.

## Como rodar

Abra o arquivo `index.html` diretamente no navegador.

🐾 *Tatui aprova rotas com areia, mar e vento no ponto certo.*
